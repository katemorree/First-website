A hardware wallet keeps your private keys on a small device that never exposes them to the internet. For anyone holding more than they'd be comfortable losing, it's the single best security upgrade.

## Quick comparison

| | Ledger | Trezor | Coldcard |
| --- | --- | --- | --- |
| Best for | Many different coins | Open-source security | Bitcoin-only, maximum security |
| Coin support | Very wide | Wide | Bitcoin only |
| Open-source firmware | Partly | Yes | Code viewable (source-available) |
| Beginner friendly | Yes | Yes | No |
| Starting price* | ~$79 | ~$59 | ~$150 |

*Prices are approximate and change often. Check the official stores.

## Buying safely

- **Only buy from the official website** or an authorised reseller.
- **Never use a device that arrives with a recovery phrase already filled in** — that's a scam.
- **Set it up yourself** and write down the phrase it generates.
